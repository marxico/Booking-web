# Booking-web

Aplicacion sencilla de reservas con frontend estatico y backend en Node.js, Express y SQLite.

## Ejecutar localmente

1. Instala dependencias:

```bash
npm install
```

2. Inicia el servidor:

```bash
npm start
```

3. Abre en tu navegador:

```text
http://localhost:3000
```

## Estructura

- `index.html`: estructura principal
- `styles.css`: estilos
- `script.js`: logica del frontend
- `server.js`: servidor Express y endpoints
- `appointments.db`: base de datos SQLite local
