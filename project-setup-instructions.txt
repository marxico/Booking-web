Project setup instructions
==========================

Production branch:
newmain

What this project uses:
- React + Vite public frontend
- Node.js + Express backend with TypeScript runtime
- SQLite production database in data/production.sqlite
- Square live payments for required booking fees
- Cloudflare Turnstile for booking abuse protection
- Encrypted customer fields and encrypted database backups

Local URLs:
- Website: http://localhost:3000/
- Admin login: http://localhost:3000/lawson-portal

Production environment:
- Copy .env.example to .env on the server.
- Set SITE_URL to the real HTTPS domain.
- Set DATA_ENCRYPTION_KEY to at least 32 random characters and store it in a password manager.
- Set ADMIN_PASSWORD to a strong unique password.
- Set live Square credentials.
- Set Cloudflare Turnstile site and secret keys.

Production commands:
- npm install
- npm run build
- npm start
- npm run backup:db

Docker production command:
- docker compose up -d --build

Security notes:
- Do not commit .env, data/*.sqlite, backups, logs, or admin-credentials.txt.
- The app refuses to start in production without Square credentials, a strong admin password, and DATA_ENCRYPTION_KEY.
- Customer name, phone, email, and vehicle details are encrypted in SQLite when DATA_ENCRYPTION_KEY is set.
- Backups are encrypted by default and end with .sqlite.enc.
- The admin dashboard is not served without a valid admin session.

SEO notes:
- Public URLs are listed in /sitemap.xml.
- Admin and login URLs are blocked in /robots.txt and marked noindex.
- Set SITE_URL correctly before submitting the sitemap to Google Search Console.
